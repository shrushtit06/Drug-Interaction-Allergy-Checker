    What the app is doing

      Results

      A Ribbon filter answers one question, very fast

      The question is: is this pair of medicines on the interaction list? The filter replies with one of two answers.

      Definitely not

      The pair is not on the list. The app stops here and skips the table lookup.

      Maybe

      The pair is probably on the list. The app confirms it in the full table.

      It never says "definitely not" for a pair that is really on the list. Now and then it says "maybe" for a pair that is not. That is a false alarm, and the table lookup catches it before you see anything.

      How it works, in plain words

      Picture a doorman with no guest list, only a few coded notes. He can say "you are definitely not on the list" with certainty, or "you probably are". The coded notes are the Ribbon filter.

      1. Every listed pair becomes an equation

        The pair's name is hashed three ways: where to start in a row of slots, which of the next 32 slots to use, and a short fingerprint. The rule is that the chosen slots, XORed together, must equal the fingerprint.

      2. All equations are solved once

        Each equation touches only 32 neighbouring slots, so together they form a thin diagonal band, a ribbon. That makes solving fast. The pair names are then thrown away and only the solved slots stay.

      3. A lookup repeats the sum

        Hash the pair again, XOR the same slots and compare. A listed pair always matches. An unlisted pair matches only by luck, about 1 time in 2r for an r-bit fingerprint.

      Good to know: the filter is built once and cannot be edited, so adding an interaction means rebuilding it. For a few hundred pairs a plain table is also quick. A filter pays off when the table is huge or far away.

      How the filter is built

      Change the fingerprint size

      A longer fingerprint means fewer false alarms but a bigger filter. Move the slider and the filter is rebuilt from the real dataset. A Bloom filter, the older and better known design, is built for the same false alarm rate so you can compare sizes.

      Where it sits in this project

      Dataset: hand-curated sample of well-known interactions, for learning only. Replace data/interactions.json with a licensed source such as DrugBank or DDInter to scale up.
